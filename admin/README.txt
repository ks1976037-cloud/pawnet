PAW NET ADMIN DASHBOARD (PHP FRONTEND DEMO)

Files:
- index.php        Admin overview dashboard
- pets.php         Pet management demo
- applications.php Adoption application status demo
- sidebar.php      Shared sidebar navigation
- header.php       Shared search, notification, location, and profile bar
- style.css        Shared purple/white responsive styling
- script.js        Frontend-only demo interactions

Run:
1. Install PHP if it is not installed.
2. Open a terminal in this folder.
3. Run: php -S localhost:8000
4. Open http://localhost:8000

No database or backend storage is used. Sample changes are temporary and may disappear when the page is refreshed. Browser geolocation requires permission and usually works on localhost or HTTPS.
